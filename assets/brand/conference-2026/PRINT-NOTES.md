# domains.domains conference artwork

Production artwork: shirt-back-white.svg on a dark shirt, shirt-back-forest.svg on a light shirt. Left chest: matching chest-mark SVG. All lettering is outlined vector paths; no font installation required. SVG backgrounds are transparent. PNGs are transparent, 300 DPI at their intended size.

Back artwork canvas: 280 x 224 mm. Left chest: 80 x 50 mm. Ink: warm white (ask printer for physical swatch), forest green #21342a, or black. One colour, no gradients. Printer should confirm garment, actual ink, placement, and a physical test print. Keep 12 mm clear space around the mark.

The AI-generated tshirt-concept.png is a visual concept. The SVG files and logo-proof.png define the final production geometry; these differ slightly from the concept. Do not print the concept board.

Do not add a QR code for domains.domains until that URL leads to the intended SaaS signup journey. The current root is still the legacy collection. No conference name, date, or affiliation is printed.
