# Optional changelog descriptions

The publisher adds releases and source/deployment events automatically. A JSON
file named for a stable entry ID can supply a clearer description or verified
status. Use the same entry shape as the legacy feed: id, UTC date, core/saas
layer, title, status, changes and project-repository evidence links.

Notes enrich the automatic archive. They never delete historical IDs or links.
Deployment claims need verified public evidence; merges and published packages
remain distinct from hosted rollout. No note is required to capture a new event.
